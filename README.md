## SEO e domínio oficial

- A origem pública atual é `https://dr-ramon-advogado.lovable.app`; URLs de prévia não são usadas como canônicas.
- Ao conectar o domínio oficial, defina a variável pública de compilação `VITE_SITE_URL` com sua origem HTTPS (sem caminho). Ela atualiza canonical, Open Graph, imagem social, dados estruturados e sitemap.
- Atualize também a linha `Sitemap:` em `public/robots.txt` para o mesmo domínio e publique novamente. Confira `/sitemap.xml`, `/robots.txt` e `/ramon-alves-compartilhamento.jpg` no domínio novo.
- A imagem social é uma cópia JPEG 1200×630 da fotografia original; a fotografia exibida no site permanece intacta e importada localmente. A marca tipográfica permanece inalterada; não foi inventado um arquivo de logo para os dados estruturados.
- O HTML e os metadados são renderizados no servidor. Uma hospedagem externa precisa suportar a aplicação TanStack Start e seu ambiente de execução; enviar somente arquivos-fonte para uma hospedagem estática não substitui essa configuração.
- Nenhuma integração com Search Console, Analytics ou rastreadores foi adicionada. SEO técnico não comprova indexação nem melhoria de posições no Google.
